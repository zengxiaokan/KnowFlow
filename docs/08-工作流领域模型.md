# 08：工作流领域模型

## 概念

首版采用线性 JSON 定义，不做图形画布。一个 Workflow 有多个版本；每次执行固定到某个版本并产生 WorkflowRun 和 StepRun。

## 本阶段目标

支持四类节点：input、retrieve、prompt、llm。

## 操作步骤

在工作流页面使用默认 JSON 创建流程。双花括号变量引用前序节点或运行输入。

## 编码任务

创建“根据知识库资料生成会议摘要”的流程：输入主题 → 检索 → 提示词 → LLM。

## 验收清单

- 每个节点有独立状态与输入输出
- 工作流失败能定位到失败节点
- LLM 节点用量写入统一用量表

## 常见错误

首版不要允许任意 Python、Shell 或 URL 回调节点；它们会把工作流变成权限和安全边界不清的远程执行器。

## 延伸阅读

后续才考虑分支、人工审批、定时触发器和画布编辑器。
