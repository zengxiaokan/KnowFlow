# 04：文档解析与 RAG

## 概念

RAG 是“提取 → 切片 → 向量化 → 检索 → 生成”的组合，不是把整个文件塞进提示词。

## 本阶段目标

支持文本型 PDF、DOCX、Markdown；每块为 500–800 中文字符左右并保留标题上下文和重叠文本。

## 操作步骤

查看 parsers.py、chunking.py 与 tasks.py。PDF 文字少于阈值会被识别为扫描件而失败，不进行伪 OCR。

## 编码任务

准备一份有标题、段落和超长段落的 Markdown，检查切片没有空块、编号连续且有重叠。

## 验收清单

- 支持文件生成 ready 文档与 Chunk
- 扫描 PDF 显示 scanned_pdf 错误
- 超页数与不支持后缀有明确错误

## 常见错误

不要在每次模型升级后混用不同维度的向量；变更 Embedding 模型维度必须建立新索引版本。
