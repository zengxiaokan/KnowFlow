# 00：环境准备

## 概念

Docker 将 Web、Worker、数据库和 Redis 固定为同一套可复现环境；Windows 本机无需安装 PostgreSQL 或 Redis。

## 本阶段目标

准备 Docker Desktop（启用 WSL2）、Git 和浏览器；复制 .env.example 为 .env，在其中填入两个模型 API Key。

## 操作步骤

执行 docker compose up --build，访问注册页创建账号。开发时用 docker compose down 停止；数据位于命名卷，停止不会删除。

## 编码任务

阅读 compose.yaml：识别 web、worker、db、redis 的职责与依赖关系。

## 验收清单

- 浏览器能访问 localhost:8000
- docker compose ps 中四个服务均运行
- /api/docs/ 能打开 OpenAPI 页面

## 常见错误

端口 8000 被占用时，修改 compose.yaml 左侧端口；Worker 无法向量化通常是 .env 缺少 SiliconFlow Key。

## 延伸阅读

阅读 Docker Compose 官方入门文档，并尝试解释为什么 Worker 不应放在 Web 进程中。
