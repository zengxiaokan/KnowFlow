# 03：Celery 异步任务

## 概念

任务状态是业务数据，不依赖 Celery result backend：IngestionTask 保存阶段、进度、错误码、开始结束时间和尝试次数。

## 本阶段目标

掌握“可重试但不重复写入”的任务设计。

## 操作步骤

沿着 enqueue_ingestion() 到 process_document() 阅读。它在提交事务后投递任务，失败时对供应商故障做指数退避，最终失败会同步更新文档状态。

## 编码任务

在任务中增加一个新阶段时，同时更新枚举、事件、页面文案和测试。

## 验收清单

- 供应商短暂不可用时任务最多自动重试 3 次
- 手工重试复用同一任务记录，并清空旧错误
- 成功重试不会留下旧版本的重复 Chunk

## 常见错误

不要在数据库事务提交前调用 .delay()，否则 Worker 可能读取不到刚创建的记录。

## 延伸阅读

比较 at-least-once 任务投递与 exactly-once 业务写入的差异。
