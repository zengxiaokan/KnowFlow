# 02：数据模型与迁移

## 概念

组织是数据隔离根。知识库、文档、会话、用量和工作流运行均沿外键归属到 Organization。

## 本阶段目标

理解 Document 与 DocumentVersion 的区别：文档是稳定业务对象，版本保存一次可重放的解析结果；Chunk 只属于一个版本。

## 操作步骤

查看四个 app 的 models.py 和 migrations/0001_initial.py。在 PostgreSQL 中，迁移会启用 vector 扩展并创建 HNSW 余弦索引。

## 编码任务

为新字段同时修改模型、创建迁移、补充 Admin 展示和测试。

## 验收清单

- 新用户注册后有一个 owner 身份的个人组织
- 不同组织的查询无法返回彼此的知识库
- Document.current_version 只在完整索引后更新

## 常见错误

不能只在页面层过滤组织；所有 QuerySet 都要从 visible_knowledge_bases(user) 或等价的组织范围开始。

## 延伸阅读

研究 PostgreSQL 的外键、唯一约束和 pgvector HNSW 索引参数。
