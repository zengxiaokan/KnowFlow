# 07：聊天与 Token 用量

## 概念

会话、用户消息、生成中的助手消息和最终助手消息分别持久化。最近 6 条已完成消息会作为短期会话记忆传给模型；流式 delta 通过会话 WebSocket 推送。

## 本阶段目标

回答完成后保存来源和模型用量；供应商没有返回 usage 时明确标记为估算。

## 操作步骤

阅读 Conversation、Message、ModelUsageRecord 与 generate_answer()。

## 编码任务

模拟一条无 usage 的流式响应，验证 is_estimated 为 True 且 Token 数不为负。

## 验收清单

- 刷新页面后聊天记录仍存在，后续提问能够理解上一轮的指代
- 失败回答变为 failed，不会伪装为成功
- 用量可按组织查询

## 常见错误

不要记录 API Key、完整鉴权头或模型的隐含推理文本到日志或数据库。

## 延伸阅读

接入价格表前应先实现价格版本与币种，不要把临时单价硬编码。
